# CareerCraft-AI

AI-Powered Personalized Career Guidance Assistant

CareerCraft-AI is an AI-powered career guidance assistant that helps
users understand their current profile, identify skill gaps, explore
career paths, and create personalized learning roadmaps.

## Key Features

- Resume Analysis
- Profile Summary
- Skill Gap Analysis
- Personalized Career Roadmap
- Skill-based Recommendations
- AI Career Chat
- Career Guidance

## IBM Technologies Used

- IBM Granite
- IBM watsonx Prompt Lab
- watsonx Orchestrate
- IBM Bob

## How It Works

User Input
   ↓
AI / LLM Processing
   ↓
Profile & Skill Analysis
   ↓
Career Guidance
   ↓
Personalized Roadmap & Recommendations
